# ChemVision v0.3 — 無機化学の全体マップ

## GitHubへの反映

GitHubで `src/` フォルダーを開き、このZIP内の `src/` にある **App.tsx / ScopeMap.tsx / scopeData.ts / scope-map.css** をアップロードしてください。既存の `App.tsx` は置き換えます。`src` フォルダーごとではなく、その中の4ファイルをアップロードしてください。

以前の v0.2 を残すため、`PredictionPractice.tsx` と `prediction.css` は削除しないでください。また `data.ts`・`styles.css`・`main.tsx` に変更は不要です。

GitHub Actions の `Deploy ChemVision` が成功したら https://shikipon11.github.io/ChemVision/ で「全体マップ」を開き、収録済みの5反応への移動と各単元の一覧・検索を確認してください。

このリリースは学習範囲の**索引**を追加します。44テーマすべての詳しい教材・アニメーションが完成したわけではありません。現在の5つの沈殿反応だけが「アニメーションあり」です。

## 学習内容の根拠

- 文部科学省・高等学校学習指導要領解説 理科編 理数編（2018年告示、2023年公開版） https://www.mext.go.jp/content/20230626-mxt_kyoikujinzai02-000033064_06.pdf
- 区分・項目名は ChemVision が教材管理しやすいように編集したものです。公式の項目一覧と一対一に対応するものではありません。
- 上記の資料は2年以上前の資料です。将来の改訂や最新の入試要項も確認する方針です。

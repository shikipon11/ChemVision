# ChemVision v0.1 — 無機化学・沈殿反応編

高校化学の反応を粒子モデルで観察し、物質図鑑・暗記カード・確認問題で学ぶ、ローカルで動くWebアプリです。

## 準備（Windows + Visual Studio Code を想定）

1. Visual Studio Code をインストール： https://code.visualstudio.com/
2. Node.js の LTS（長期サポート版）をインストール： https://nodejs.org/
3. `ChemVision.zip` を「すべて展開」する。
4. VS Code →「ファイル」→「フォルダーを開く」で、展開した `ChemVision` フォルダーを選ぶ。
5. VS Code メニュー「ターミナル」→「新しいターミナル」を開く。
6. **最初の1回のみ**、次を入力して Enter：

   ```bash
   npm install
   ```

7. 次を入力して Enter：

   ```bash
   npm run dev
   ```

8. ターミナルに表示されるURL（通常 `http://127.0.0.1:5173/`）をブラウザで開く。

停止するには、VS Code のターミナルで `Ctrl + C`。次回の起動は `npm run dev` のみです。

**補足：** `npm install` では公開npmレジストリからReactなどの開発用パッケージを取得するため、初回はインターネット接続が必要です。URLのポート番号は環境によって変わります。ターミナルに表示されたURLを使用してください。

## 搭載機能

- ホーム：学習枚数、復習可能枚数、確認問題の最高記録を表示。
- 反応：AgCl、BaSO₄、Cu(OH)₂、Fe(OH)₃、CaCO₃の沈殿生成5種類。反応前→混合→反応後の粒子モデル、再生・一時停止・速度変更、傍観イオンの表示切替。
- 図鑑：化学式・物質名・性質から検索できる14物質。反応ページに移動可能。
- 暗記カード：20枚。自己評価「忘れた」「あやふや」「覚えた」に応じて1日・3日・7日後を復習目安として記録。
- 確認問題：12問。即時採点、解説、反応ページへのリンク。
- 学習履歴：端末の同じブラウザ内の `localStorage` に保存。アカウントやサーバーは不要。

## フォルダー

- `src/data.ts`：化学反応、物質、暗記カード、確認問題のデータ。
- `src/App.tsx`：Reactの画面、SVG粒子モデル、学習機能と画面遷移。
- `src/styles.css`：デザインとスマートフォン対応。
- `src/main.tsx`：アプリの起動処理。

## 化学表現の注意

粒子モデルは高校化学の理解のための**模式図**です。実際のイオンの大きさ、濃度、粒子数、溶媒和、速度、結晶格子を厳密に表したシミュレーションではありません。実験手順を指示するアプリではありません。

## 困ったときは

- `npm` が見つからない：Node.jsを入れた後、VS Codeをいったん閉じて開き直す。
- 起動しない：VS Codeのターミナルに表示された**エラーメッセージ全文**をチャットに貼り付ける（個人情報は伏せてね）。
- 画面が空白：ブラウザで更新し、ターミナルのエラーを確認する。

### Windowsで「このシステムではスクリプトの実行が無効」と表示される場合

VS Codeのターミナル右上のメニューから「既定のプロファイルの選択」→「Command Prompt（コマンド プロンプト）」を選び、新しいターミナルを開いて `npm install` から実行してください。PC全体のセキュリティ設定を変更する必要はありません。

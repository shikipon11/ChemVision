# ChemVision v0.4 — 高校無機化学の学習アプリ

化学反応を模式的な粒子モデルで観察し、物質図鑑・反応ノート・暗記カード・確認問題で学ぶReact製のWebアプリです。

## 学習コンテンツ

- 物質図鑑：57種（物質名・化学式・外観・溶解性・関連知識）。
- 反応ライブラリ：既存の沈殿反応5種を粒子モデルで可視化。
- 反応ノート：無機化学の代表的な反応26件。式・結果・理由を確認。**アニメーションではありません**。
- 暗記カード：89枚。既存の学習履歴を維持。
- 確認問題：36問。既存の学習履歴を維持。
- 全体マップ：44学習テーマ。アニメーション・反応ノートの対応状況を表示。

本バージョンは高校化学の全範囲を収録したものではありません。反応ノートは教育用の総括式であり、実験操作の指示ではありません。

## ローカル開発（Windows / VS Code）

Node.jsのLTS版を導入し、プロジェクト直下（`package.json`のある場所）で：

```cmd
npm.cmd install
npm.cmd run dev
```

表示されたURLをブラウザで開いてください。停止はターミナルで Ctrl+C。

教材検証は `npm.cmd run check:content`、本番用ビルドは `npm.cmd run build` です。ビルドの前に教材検証が自動実行されます。

## 主なファイル

- `src/data.ts`：既存の物質・反応・カード・問題のデータと追加データの結合。
- `src/expandedData.ts`：v0.4追加教材。データと表示ロジックは分離。
- `src/App.tsx`：画面・ナビゲーション・既存アニメーション・復習。
- `src/ReactionNotebook.tsx`：反応ノート。
- `src/ScopeMap.tsx`：学習マップと教材へのリンク。
- `scripts/check-content.cjs`：ID・リンク・4択・原子数の検査。

## 化学データの検査範囲

反応式の原子数整合性は検査していますが、電荷・反応条件・色・平衡・教育上の適切さを保証するものではありません。教材として一般公開する前に専門的な内容確認が必要です。粒子モデルは実際の粒子の大きさや速度を再現するものではありません。
